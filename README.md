# Ghost Carbon: Claimed vs Measured Compute Carbon for Common ML Training Recipes

Compare marketing-style green claims against bottom-up training/inference energy and CO2e estimates.

## This repository is independent
No shared code or data dependencies with the sibling environment papers.

## Quickstart
```bash
pip install numpy pandas scikit-learn matplotlib
jupyter notebook notebook/ghost-carbon-ml-claims.ipynb
```

Or open the notebook on Kaggle and Run All.
